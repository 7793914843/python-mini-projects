 Python Mini Projects

A collection of 10 beginner-friendly Python mini projects built to practice programming fundamentals, problem-solving, and basic application development.

 📚 Projects

| No. | Project | Description |
|---|---|---|
| 01 | ATM Simulation | Simulates basic ATM operations like balance checking, deposit, withdrawal, and PIN verification. |
| 02 | To-Do List | A simple task management program to add, view, and remove tasks. |
| 03 | Calculator GUI | A graphical calculator built using Python Tkinter. |
| 04 | Password Generator | Generates random and secure passwords based on the required length. |
| 05 | Number Guessing Game | A game where the user tries to guess a randomly generated number. |
| 06 | Tic Tac Toe | A two-player console-based Tic Tac Toe game. |
| 07 | Expense Tracker | Tracks daily expenses and helps manage spending records. |
| 08 | Contact Book | Stores and manages contact information such as names and phone numbers. |
| 09 | Library Management System | Manages books and basic library operations. |
| 10 | Student Management System | Stores, searches, updates, and manages student records using JSON. |
